# Air-Quality-Data-Analysis-Dashboard
My College project 
Air Quality Data Analysis Dashboard

Project Description

This is a simple web-based project used to check Air Quality Index (AQI) values and understand air quality.

Features

- Enter AQI value from 0 to 500.
- Check air quality using the entered value.
- Display air quality status.
- Simple and user-friendly interface.

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Open the Air Quality Dashboard.
2. Enter an AQI value between 0 and 500.
3. Click on the Check Air Quality button.
4. View the air quality result.

Project Purpose

The purpose of this project is to help users understand air quality levels easily.
